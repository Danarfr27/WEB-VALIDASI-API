# Bulk API Key Checker

This is a minimal Next.js app (ready for Vercel) that checks API keys in bulk and provides downloads for active and invalid keys in `.txt` format.

Quick start (local):

```bash
npm install
npm run dev
# open http://localhost:3000
```

Deploy to Vercel: push to a Git provider and deploy with Vercel. The `pages/api/check` route runs server-side and performs the checks.
